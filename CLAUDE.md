# CLAUDE.md

Las reglas de este proyecto están en [AGENTS.md](./AGENTS.md) y la especificación en [docs/spec.md](./docs/spec.md). Leelos antes de escribir código: este archivo existe solo para que Claude Code los encuentre, y no repite ninguna regla.

Antes de dar un cambio por terminado, corré `npm run typecheck`, `npm run lint` y `npm test` (y `npm run test:e2e` si tocaste pantallas, permisos o el flujo principal).
